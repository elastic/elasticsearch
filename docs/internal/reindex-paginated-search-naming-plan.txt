Reindex: Scroll → PaginatedSearch Naming Plan
==============================================

Scope: modules/reindex and server/src/main/java/org/elasticsearch/index/reindex (plus their tests)
Convention: Replace generic "Scroll" / "BulkByScroll" naming with "PaginatedSearch" where it refers
to the reindex pagination abstraction — not the Elasticsearch Scroll API itself.
Reference PR: https://github.com/elastic/elasticsearch/pull/153387


Already in PR #153387 (not yet on main)

[[bug-8.19.23]]
[float]
=== Bug fixes

ES|QL::
* Fixes a `NullPointerException` that occurred when ES|QL folded a regular expression that evaluated to `null` {es-pull}158768[#158768] (issue: {es-issue}158748[#158748])
* Fixes the `isPartial` flag in ES|QL responses so that it is set correctly {es-pull}157475[#157475] (issue: {es-issue}157440[#157440])
* Fixes ES|QL queries on indices where a nested field conflicts with an object field {es-pull}158573[#158573] (issue: {es-issue}154011[#154011])
* Makes the ES|QL `TO_BASE64`, `FROM_BASE64`, `MV_ZIP`, and `MV_CONCAT` functions respect the circuit breaker, so large inputs return a circuit breaker error instead of exhausting memory {es-pull}159659[#159659]
* Returns `null` values and a warning, rather than failing the query, when a typed `GROK` capture such as `%{NUMBER:n:int}` matches a value that can't be converted to the requested type {es-pull}160574[#160574]

Extract&Transform::
* Limits the length of a connector description to 8192 characters {es-pull}159638[#159638]

Geo::
* Fixes the latitude correction in H3 cell bounds calculations so that it checks both edges adjacent to the extreme-latitude vertex {es-pull}160228[#160228] (issue: {es-issue}159682[#159682])
* Limits the nesting depth of geometry collections when a geometry is created, preventing excessive recursion when a `geo_shape` runtime field emits deeply nested geometries {es-pull}160004[#160004]

Infra/Core::
* Ignores unrelated files when scanning the configuration directory for `log4j2.properties` {es-pull}150016[#150016]

Machine Learning::
* Adds the `max_consecutive_extraction_failures` datafeed setting. A real-time datafeed now stops automatically after repeated consecutive extraction failures instead of retrying indefinitely {es-pull}159554[#159554] (issue: {es-issue}158426[#158426])

Search::
* Improves consistency checks for point in time (PIT) IDs {es-pull}160179[#160179]
* Fixes a memory leak where shard results that arrived after a search phase failed were never released {es-pull}160439[#160439] (issue: {es-issue}160321[#160321])

Security::
* Improves consistency checks for shard-level requests {es-pull}159691[#159691]

Templates::
* Reduces memory usage when retrieving component templates and composable index templates by streaming the response from the get component template and get index template APIs {es-pull}158175[#158175]

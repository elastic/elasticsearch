# Phonetic token filter for text analysis [analysis-phonetic-tokenfilter]


The `phonetic` token filter is provided as the [`analysis-phonetic`](/reference/elasticsearch-plugins/analysis-phonetic.md) plugin.

{{serverless-full}} includes the plugin by default. In {{stack}}, follow the [plugin installation instructions for your deployment type](docs-content://deploy-manage/plugins-and-custom-configuration-files.md#plugins-by-deployment-type).

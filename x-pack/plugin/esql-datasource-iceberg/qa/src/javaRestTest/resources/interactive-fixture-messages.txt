[example_queries]

🔍 EXAMPLE QUERIES (data source + dataset, queried with FROM)

  Step 1: register a data source pointing at the S3 fixture
  ─────────────────────────────────────────────────────────
  curl -X PUT "{{es_url}}/_query/data_source/fixture_s3" \
    -H 'Content-Type: application/json' -d'{
    "type": "s3",
    "settings": { "endpoint": "{{s3_endpoint}}", "auth": "anonymous" }
  }'

  Step 2: register a dataset over the standalone parquet file
  ───────────────────────────────────────────────────────────
  curl -X PUT "{{es_url}}/_query/dataset/employees" \
    -H 'Content-Type: application/json' -d'{
    "data_source": "fixture_s3",
    "resource": "s3://{{bucket}}/{{warehouse}}/standalone/employees.parquet"
  }'

  Step 3: query the dataset
  ─────────────────────────
  curl -X POST "{{es_url}}/_query?format=txt" \
    -H 'Content-Type: application/json' -d'{
    "query": "FROM employees | LIMIT 5"
  }'

  Kibana Dev Console
